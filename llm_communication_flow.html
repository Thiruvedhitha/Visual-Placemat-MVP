⑤ ReactFlow Execution — how commands become canvas nodes

Every LLM command (from AI Editor or Transcript apply) goes through the same executeCommands() pipeline. No ReactFlow API is called directly — Zustand state changes cause ReactFlow to re-render.

Commands in
onAICommands(commands[]) called in dashboard page
Source: AIMapEditor mode=command, or proposal Accept, or transcript apply.
All paths converge at applyAICommands(commands) in dashboard/page.tsx.

Execute

Undo Stack
Command history for undo — local only
Each accepted command is pushed onto a local undo stack in Zustand. Undo replays the inverse operation locally — does not call any API. Only "Apply" persists to DB, so undone changes that were never applied are never written.
